# 🔗 Linktree

Este projeto é uma página inspirada no **Linktree**, criada para reunir diferentes links e redes sociais em um único lugar.

## 💻 Sobre o projeto

A página foi desenvolvida como um projeto para praticar **desenvolvimento web** e criação de interfaces.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS

## ✨ Funcionalidades

- Links para redes sociais
- Perfil com imagem e informações
- Design simples 
- Organização de vários links em uma única página

## 🎯 Objetivo

O objetivo do projeto é colocar em prática conhecimentos de **HTML e CSS**, criando uma página de apresentação pessoal com acesso rápido aos principais links.
